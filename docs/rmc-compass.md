# RMC-COMPASS: rounded public model in Python

Entry **174 is partial**. The live institutional app's model panel exposes a
log-normal accelerated-failure-time equation and rounded parameters. Python
now provides approximate point predictions from that panel, without contacting
the app. The full fitted model and its confidence-interval calculation remain
unavailable.

```python
from mdanderson_stats import rmc_compass_reported_prediction

prediction = rmc_compass_reported_prediction(
    1,
    0,  # ECOG performance status and number of involved disease sites
    neutrophil_lymphocyte_ratio=5 / 1.5,
    corrected_calcium_mg_dl=9.5,
)
print(prediction.survival_probability)  # 6, 12, 18, 24, 36 months
print(prediction.risk_group)  # Intermediate
```

Supply an already computed neutrophil/lymphocyte ratio and corrected calcium
in mg/dL. This API does not reproduce the app's raw laboratory-input handling.
ECOG must be 0–4; the count of involved sites must be 0–11. The site identities
do not enter the fitted equation. Continuous values are held within the
**displayed** development ranges, NLR 0.84–22 and calcium 8.3–11.2; the result
retains raw/effective values and identifies clamping. The native limits may
have additional undisclosed digits. ECOG 4 and site counts above 7 are flagged
as extrapolation and remain in the equation. Times are in months, from 0 to 36;
the array order and duplicate times are preserved. At time zero survival is 1.

## Recovered equation and precision

The observed **V1.0.2.0**, updated September 15, 2026, reports:

```text
LP = 5.7273 + 0.895 * (
    -0.3932 * ECOG
    -0.1104 * disease_site_count
    -0.0261 * NLR
    -0.2636 * corrected_calcium
)
S(t) = Φ((LP - log(t)) / 0.8334)
median survival = exp(LP) months
```

The risk group uses 24-month survival: below 0.25 is High, above 0.50 is Low,
and both cutoffs themselves belong to Intermediate. Arrays are immutable.
The public app describes a single-institution cohort of 180 patients with
SMARCB1-deficient renal medullary carcinoma, 142 deaths, and internal bootstrap
validation without external validation.

The default Python median is about **21.248 months**; the native app displays
**21.3 months**. This is a real precision difference. The public coefficients
do not identify the unrounded fit. Do not treat Python results as exact native
predictions or claim equivalence merely because some displayed probabilities
match.

`survival_parameter_rounding_envelope` and
`median_parameter_rounding_envelope` propagate half a last displayed digit
for the intercept, coefficients, shrinkage and sigma. They assume nearest
rounding and hold effective inputs fixed. They are **not confidence intervals**,
exclude sampling uncertainty and uncertainty about native clamping precision,
and do not establish that the hidden fit used those rounding conventions.
The result also indicates when parameter rounding alone could change the risk
group. Native confidence intervals require the original fit/covariance or
posterior/resampling draws and the interval algorithm; none are synthesized.

and eleven medians/groups, including the native clamping/extrapolation paths.
Their displayed rounding intervals intersect the Python parameter-rounding
envelopes. These are independent observations from the public calculator,
