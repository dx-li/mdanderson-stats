# Complete BARD BF-BOIN trial

`run_bard_bf_boin_trial` composes the existing calendar-time BF-BOIN simulator
with BARD's covariate-adaptive stage-two allocation and two final OBD analyses.
It preserves every stage-one and stage-two patient, including dose, factors,
DLT/response, arrival and assessment times, and the response probabilities used
to generate each outcome. `BARDStageTwoDesign` freezes the carryover eligibility,
transition pair, allocation settings, and OBD settings. The result also retains
the actual stage-one and stage-two settings, response model, truth, and RNG seed
when the seed was supplied or generated by the function.

```python
from itertools import product

from mdanderson_stats import (
    BARDStageTwoDesign,
    BFBOINDesign,
    bard_response_model,
    run_bard_bf_boin_trial,
)

profiles = list(product((1, 2), repeat=2))
response_model = bard_response_model([0.20, 0.32, 0.45], profiles, [0.25] * 4, [[1, 1.5], [1, 0.8]])
stage_two = BARDStageTwoDesign(
    total_target=14,
    eligible_profiles=[True, True, True, False],
    prior=[0.25, 0.25, 0.25, 0.25],
    safety_weights=[1, 1],
    toxicity_limit=0.30,
    efficacy_limit=0.20,
    safety_cutoff=0.95,
    efficacy_cutoff=0.95,
    utilities=[0, 30, 50, 100],
    margin=0.05,
    tie_arm=1,
    stage_two_accrual_rate=2.0,
    dose_pair=(1, 2),  # Explicit pair; no native pair optimizer is inferred.
    balanced_factors=(0, 1),  # Zero-based columns; this example balances both.
)
trial = run_bard_bf_boin_trial(
    BFBOINDesign(target=0.25, n_cap=6, elimination_probability=0.99),
    [0.08, 0.18, 0.30],
    response_model,
    stage_two,
    cohorts=3,
    cohort_size=3,
    rng=912,
)
print(trial.status, trial.total_sample_size, trial.duration)
print(trial.selected_dose_noninferiority, trial.selected_dose_utility)
```

The transition pair defaults to the selected stage-one MTD and its adjacent
lower dose. An explicit valid pair may be supplied, but it cannot reopen a
stage-one no-MTD/safety stop or include a dose marked unsafe by the retained
BF-BOIN elimination history. If the selected MTD is dose 1, the default has no
lower transition dose and stage two is not run. These cases remain represented
in simulation denominators through the returned status.

`eligible_profiles` is a Boolean vector aligned with the response model's
profile rows. It defines which profiles can enter stage two and which stage-one
patients are mandatory carryover when assigned to the pair. Stage-two profile
weights default to the response model's weights; any supplied weights are
conditioned on the eligible profiles and renormalized. This does not recalibrate
the response model, so its population margins remain tied to the original
profile distribution.

`total_target` is inclusive of all eligible stage-one pair patients. If those
mandatory patients exceed the target, all are retained, no new patients are
enrolled, and status is `carryover_exceeds_target`; the design never silently
discards an eligible patient. No arm-specific quotas are imposed. BARD's
minimization determines assignments using `balanced_factors` (zero-based
columns; default all modeled factors). A final noninferiority analysis is
returned only when both arms have observations; the utility analysis is always
calculated when stage two runs. A missing selection is distinct from a trial
that did not run stage two.

Stage one delegates to `simulate_bf_boin`. Stage two begins at the end of
stage-one complete follow-up, enrolls the first new patient at that time, then
uses the configured uniform or exponential renewal gaps. DLT event times use
the same Weibull window calibration as BF-BOIN; response assessment occurs at
the end of the DLT window. This is an explicit Python calendar convention,
not a claim about undocumented native stage-two timing. A supplied
`joint_toxicity_response_probability[dose, profile]` applies to both stages;
the stage-two design can override it. Without a joint probability, DLT and
response are conditionally independent given dose and factor profile.

The method follows the source's inclusive total enrollment, carryover,
covariate-adaptive allocation, and final utility/noninferiority analyses. The
paper's usual MTD-plus-adjacent-lower pair, native profile eligibility controls,
and hidden defaults are not inferred. [Stage-two source and scope audit](../research/bard-bf-boin-trial-audit.md)
records remaining differences, including native saved protocol/report output.
