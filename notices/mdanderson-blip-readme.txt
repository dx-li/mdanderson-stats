BLiP Plot

Four files are contained in this package:

1. README: this file.
2. blip.s: the S source code for generating the BLiP plot.
3. blip: the S help file.  Please move to the appropriate .Data/.Help subdirectory.
4. paper.s: the S code to generate the graphs appeared in the paper referenced below.

The function 'blip()' provides a flexible environment for users to draw standard or
customized one-dimensional distribution plots to best present their data.

Reference: Lee, J.J., Tu, Z. N.:"A Versatile One-dimensional Distribution Plot: 
The BLiP Plot", The American Statistician 51:353-358, 1997.
