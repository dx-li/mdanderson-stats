# Native report edge audit

`tools/reference_wfmm_report_edges.py` pins the original WFMM1/2/3 hashes,
creates only synthetic inputs, and supplies beta and variance draws explicitly.
The adjacent JSON regenerated byte-identically twice in this environment.
This evidence does not claim native/Python RNG identity or clinical validity.
Original executable/library bytes remain outside artifacts.

Five cases verify pooling two 40-draw files, fitted random-function reporting,
zero/constant functions, and different quantile requests for identical beta
draws. Independent Haar synthesis reproduces saved beta arrays; reported means
and sample SDs agree with those saved draws. Original U means and SDs agree with
the saved U arrays. This verifies reporting of those draws, not their conditional
sampling distribution.

Pointwise native quantiles pass through float32 and select observed order
statistics. With the same 40 beta draws, changing the requested probability
vector changes the native .13 quantile: the six-probability request selects
zero-based rank 5; the three-probability request selects rank 4. The native
TailKeeperArray initializes tail capacities using the middle requested
probabilities (0x45b5c0) and rescales indices within retained tails (0x459420).
It is not interchangeable with a probability-by-probability standard quantile
rule. Python keeps its documented linear interpolation.

The zero-function case has native SD zero and SimBaS .001, even though an
identically zero function cannot exclude zero. This is another reason not to
adopt the original integer-truncated/grid-based SimBaS as a scientific default.
Python's existing exact empirical convention assigns one to a constant zero
function and zero to a constant nonzero function.

## Unresolved native random-function variance

The controlled random-effects case supplies Q=.3 and S=.5, two independent
random levels with four rows each, and fixed beta draws. The Gaussian
conditional variance is (1/Q + 4/S)^(-1) = .08823529411764705. Standardizing the
native U innovations using that conditional mean and variance produces sample
variance about .241 across 1,280 values, rather than near one. This is a material
unresolved discrepancy; no native conditional-variance agreement is claimed.

A child-only ptrace probe of the pinned WFMM3 constructor at 0x4a6040 found the
correct 2-by-2 diagonal covariance .08823529411764705 and mean
(.9612927822255699, 1.1591428574549474) on the first call for the controlled
scratch input. That localizes further investigation beyond the initial Gaussian
conditional covariance calculation. Scratch trace and disassembly are preserved
at /tmp/wfmm-report-edges. The production Python sampler is independently tested
against conditional Gaussian mathematics and has not been changed to match this
unresolved native output. Follow-up should trace the multivariate generator and
subsequent stored U mapping before assigning a cause.
