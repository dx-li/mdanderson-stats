# Predictor-only missing-data support for the global OOB Brier score

## Native source contract

The pinned helper `research/raw/randomForestSRC/R/utilities.survival.R:get.brier.survival` supports the standard global censor model with an OOB survival matrix and complete training outcomes. On the default full cohort, lines 291–329 obtain outcome/time information from the forest's training response and compute the global event/censor summaries from time and status alone. Lines 341–355 build the global censor-survival curve using risk counts and censor counts. Lines 379–394 evaluate each row's OOB survival curve against its outcome and this shared curve. Covariates are not inputs to the `cens.model="km"` IPCW formula.

The named `km` path in this source computes `exp(-cumsum(d/Y))`, matching the existing Python global estimator. This audit calls it the **global censor estimator** or the source `km` option; it does not replace the source formula with the product-limit Kaplan–Meier estimator. The `cens.model="rfsrc"` branch is different: lines 356–373 fits a censoring forest from `o$forest$xvar` and predicts it on `o$xvar`. That branch requires complete predictors and is not included for imputed fits.

For an imputed fit with complete retained time/status and missing predictors only, the OOB forest already contains valid predictions for every retained training row. The global censoring and IPCW terms use only the complete outcomes and those OOB curves. The adapter therefore accepts this case only when the original-input fingerprint matches, the fit row map matches preprocessing of rows with every outcome and predictor missing, retained times/statuses are finite, and retained predictors contain missing values. It intentionally does not interpret an imputed event time or event indicator as an observed outcome. Rows dropped because all inputs are missing are excluded from the Brier result by the fit's original-row map; a partially observed row with missing time or status is rejected.

## Python behavior and limits

`random_survival_forest_oob_brier_score(..., censor_model="km")` now supports actual predictor-only imputation. It still uses the OOB survival curves from the fitted forest and computes the same global censor weights on original complete retained outcomes. Original predictor values and missingness/order are checked with `original_training_fingerprint`; the fit's completed or placeholder predictor matrix is never mistaken for caller input. `censor_model="rfsrc"` remains an explicit error for actual imputation because the secondary censoring forest's missing-predictor semantics are outside this change. Missing retained outcomes and imputed VIMP are also rejected. Omitted fits retain their existing row-map behavior.

The output is full training-row order for predictor-only imputed fits. As in the existing API, rows with no OOB contributors have NaN Brier curves and do not enter per-time means. The source event-interest grid is based on event times, while the forest master time grid used by imputation includes every original non-NaN response time, including censor times and rows with missing status (`randomForestSRC.c:24834–24880`; `R/utilities.survival.R:89–92`). These grids serve different purposes.

The focused regression test calculates the global censor curve and every row/time Brier contribution independently from the source equations using a real categorical-plus-numeric predictor-only imputed OOB fit. It also checks original-input mismatch, dropped all-missing-row mapping, rejection of retained missing outcomes, explicit rejection of the covariate-dependent `rfsrc` censor model, and continued VIMP refusal. Global censor weights remain positive on the event-interest grid because each event-grid risk set contains an observed event; zero-G terms therefore do not arise for this finite-sample global estimator.
