# EffTox 5.2.3 binary workflow acceptance

The declared completion scope is the currently advertised six-coefficient binary
GUI workflow. Historical four-coefficient XML migration, old trinary GUI behavior,
Windows binary identity, numerical integrator/optimizer identity and random-stream
identity are separate compatibility claims. Existing historical mathematical APIs
and their qualifications remain documented; none is silently substituted for
the current saved model.

| Declared workflow | Delivered interface and evidence |
| --- | --- |
| Saved study and elicitation | Current XML reader retains metadata and administered/calculated dose distinction; input/output prior precedence enforced; independent adaptive calibration returns residuals, optimizer and quadrature diagnostics. |
| Patient conduct | Add, update, last/all deletion, file-mode transitions, complete/partial cohorts, bounded pending completions and safe capacity behavior; source controller/cohort/consensus references. |
| Statistical decisions | Six-parameter Gaussian prior and joint likelihood; posterior means, tail cutoffs, reachability and selection; original integrand plus decision references. Explicit slope-prior choice and separate legacy summary profile. |
| Simulation | Complete cohorts and final refit, early stopping, all saved scenarios, separate outcome/sampler seeds, whole-request work bounds, repeated batches with weighted aggregation. |
| Reports | Escaped standalone conduct/simulation/batch HTML; inputs, truth, posterior/prior summaries, allocation, selection/no-selection, Rselect, actual sampler settings and diagnostics. |
| Independent acceptance | 738 current native instruction cases; independent R mathematical checks; original distributed saved-file exercise; installed-wheel regressions and precision comparison. See the validation manifest. |

Native negative-slope toxicity summaries are inconsistent with the likelihood;
only `desktop_legacy` reproduces that defect. Scientific defaults retain each
dose's modeled toxicity. Safe capacity handling is default; the original
partial-final-cohort defect is available only through an explicit controller
compatibility profile. Original coarse contour root tolerance is not imposed
on the more accurate Python solver.

The two-trial precision comparison retained identical observed histories and
selection at default and tripled draw/warmup settings, but worst split R-hat
was1.0740 and1.0523 respectively. This is qualified workflow stability, not a
blanket convergence or operating-characteristic accuracy guarantee. Reports
retain diagnostics so users can assess their particular analysis. Software
completion is not clinical validation.
